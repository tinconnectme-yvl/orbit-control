# Примеры сохранённых расчётов (cosmo-B-ops-result-1.0)

В этой директории представлены эталонные машиночитаемые выгрузки суточных смен спутниковой группировки, сформированные программным комплексом **«ОРБИТА-КОНТРОЛ»** (алгоритм «Вектор-Орбита»).

Каждый файл полностью соответствует официальной схеме `cosmo-B-ops-result-1.0` и содержит:
1. Исходный сценарий с параметрами среды и начальными условиями КА.
2. Полную хронологию назначенных команд по каждому 5-минутному шагу.
3. Поступившие динамические сообщения и события.
4. Итоговые показатели смены (выручка, выполненные задачи P3, состояние батарей и температур).

---

## 📁 Список примеров:
- **`result_P01_intro.json`**: Ознакомительная смена 16 КА, 48 шагов (4 часа), 18 задач. Выполнены 100% физически осуществимых задач (11 из 11), выручка $151.24, 0 потерянных шагов связи.
- **`result_P02_shift.json`**: Полная суточная смена 48 КА, 288 шагов (24 часа), 1208 задач. Выполнено 1158 задач (включая 313 из 334 критических задач P3), выручка $27,315.56, минимальный заряд батарей 48.6%, 0 brownout-аварий.

---

## 🔍 Инструкция по независимой валидации:
Для побитовой проверки соответствия расчетной модели выполните официальный валидатор организаторов:

```bash
# Валидация сценария P01_intro
python CaseInfo1/model/operations.py --result examples/result_P01_intro.json --output replay_p01.json

# Валидация суточного сценария P02_shift
python CaseInfo1/model/operations.py --result examples/result_P02_shift.json --output replay_p02.json
```

Оба расчета подтверждают 100% побитовую сходимость с физической моделью симулятора (`Replay check PASSED: 100% Bit-exact match`).
