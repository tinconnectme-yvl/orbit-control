## 🧭 О ПРОЕКТЕ
**«ОРБИТА-КОНТРОЛ»** — программный комплекс диспетчеризации и веб-сервис оператора наземного центра управления полётами (ЦУП). Система выполняет автономное планирование работы спутниковой группировки масштабом от 16 до 48 космических аппаратов с шагом 5 минут (300 секунд) на смене от 4 до 24 часов (до 288 шагов).

### Главные особенности:
1. **100% соблюдение физики среды:** Батарея $SoC \ge 30\%$ (резервный порог) и отсечка $20\%$ (критический порог), тепловой диапазон полезной нагрузки $5..45^\circ\text{C}$, регламентная калибровка раз в 48 шагов, лимит наземного сегмента (не более 2 одновременных Downlink).
2. **Алгоритм «Вектор-Орбита»:** Сочетание упреждающей калибровки, ранжирования по slack time и удельной доходности, двудольного сопоставления ретрансляций и превентивной защиты батарей.
3. **5 Киллер-фич:** Интерактивный 3D-глобус Земли с кеплеровскими орбитами и лучами связи, интерактивная матрица Ганта 48×288, инспектор телеметрии аппарата в 1 клик, Chaos Monkey (инжектор сбоев), What-If сплит-скрин сравнения стратегий и Explainable AI диагностика срывов задач.
4. **Localhost First:** Автономная работа без интернета и внешних облачных API.

## ⚡ БЫСТРЫЙ СТАРТ

### Способ 1: Запуск одной командой на локальном ПК (Рекомендуется)
Требования: Python 3.10+
```bash
python run_demo.py
```
> Скрипт проверит свободный порт (по умолчанию **8010**, с авто-поиском свободного порта) и автоматически откроет интерфейс ЦУП в браузере: `http://127.0.0.1:8010`.  
> Вы также можете вручную указать порт: `python run_demo.py --port 8080`.

### Способ 2: Запуск в Docker Compose
```bash
docker compose up --build
```
> Доступ к интерфейсу: `http://localhost:8010`  
> Документация API: `http://localhost:8010/docs`
